# Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Append-only audit log capturing every state change on audited models, every auth event, and every key domain event (approvals, rejections, payouts, role changes, settings updates). Super-admin-only viewer. No one can edit or delete entries — enforced at UI, model, and DB-grant layers.

**Architecture:**
- Uses `spatie/laravel-activitylog` v4 for the observer infrastructure and polymorphic schema.
- An `Auditable` trait wraps Spatie's `LogsActivity` with per-model retention + field redaction.
- Manual domain/auth events flow through `AuditService::record()`.
- Retention: `critical` kept forever; `standard` pruned after 90 days via a command running as a **separate DB role** with the only `DELETE` privilege on the table.

**Tech Stack:** Laravel 12, PHPUnit 11, Inertia v2, React 19, MUI, PostgreSQL, `spatie/laravel-activitylog` v4.

**Spec:** `docs/superpowers/specs/2026-04-17-audit-log-design.md`

**Branch:** `feat/audit-log` (already created, spec committed at `469be29`).

## Context the engineer needs before starting

- Existing observer pattern: `app/Providers/AppServiceProvider::boot` registers observers via `Model::observe(…)`. We will NOT add observers there — Spatie's `LogsActivity` trait wires its own via Eloquent event hooks. Other observers on the same model keep working.
- `role:super_admin` middleware is a real alias at `bootstrap/app.php:63`, backed by `EnsureUserRole`. Syntax `middleware('role:super_admin')`.
- Laravel 12 schedules live in `routes/console.php` (not `Kernel::schedule()`). That file is already actively used.
- No `EventServiceProvider` — Laravel 11+ listener auto-discovery scans `app/Listeners/` so any class with `handle(EventType $event)` is picked up automatically.
- Run tests in Docker when the host OOMs: `docker exec surprisemoi-app-local php artisan test --compact --filter=<name>`. Prefer host when it works: `php artisan test --compact --filter=<name>`.
- Run `vendor/bin/pint --dirty --format agent` before each commit.
- The `audit_log` table name — Spatie's default is `activity_log`. We keep it. All references in this plan use `activity_log`.

## Task 4: `AuditContext` request-scoped singleton

**Files:**
- Create: `app/Support/AuditContext.php`

The context carries per-request metadata (IP, user agent) that the middleware sets on request entry and every audit write reads on its way out. Static properties are fine — Laravel's worker process handles one request at a time, and Octane users would reset this in a reset hook (out of scope for v1).

- [ ] **Step 1: Create the class**

```php
<?php

namespace App\Support;

class AuditContext
{
    protected static ?string $ip = null;

    protected static ?string $userAgent = null;

    public static function set(?string $ip, ?string $userAgent): void
    {
        self::$ip = $ip;
        self::$userAgent = $userAgent;
    }

    public static function ip(): ?string
    {
        return self::$ip;
    }

    public static function userAgent(): ?string
    {
        return self::$userAgent;
    }

    public static function forget(): void
    {
        self::$ip = null;
        self::$userAgent = null;
    }

    /** @return array{ip: ?string, user_agent: ?string} */
    public static function toArray(): array
    {
        return [
            'ip' => self::$ip,
            'user_agent' => self::$userAgent,
        ];
    }
}
```

## Task 6: `Auditable` trait (redaction + retention helpers)

**Files:**
- Create: `app/Traits/Auditable.php`

The trait wraps Spatie's `LogsActivity`. Three conveniences it adds:
1. Default `logExcept()` list covering sensitive fields across the whole project.
2. `retentionClass()` method models can override (default `'standard'`).
3. Automatically stamps `ip` + `user_agent` + `retention_class` into `properties` via `tapActivity()`.

- [ ] **Step 1: Create the trait**

```php
<?php

namespace App\Traits;

use App\Support\AuditContext;
use Spatie\Activitylog\Contracts\Activity;
use Spatie\Activitylog\LogOptions;
use Spatie\Activitylog\Traits\LogsActivity;

trait Auditable
{
    use LogsActivity;

    /**
     * Sensitive fields redacted across the whole project. Individual models
     * can add more via a $auditableRedactExtra property.
     *
     * @var array<int, string>
     */
    protected array $auditableRedactDefault = [
        'password',
        'remember_token',
        'two_factor_secret',
        'two_factor_recovery_codes',
        'otp',
        'otp_expires_at',
        'paystack_recipient_code',
    ];

    public function getActivitylogOptions(): LogOptions
    {
        $redact = array_values(array_unique(array_merge(
            $this->auditableRedactDefault,
            property_exists($this, 'auditableRedactExtra') ? $this->auditableRedactExtra : []
        )));

        return LogOptions::defaults()
            ->logOnly(['*'])
            ->logExcept($redact)
            ->logOnlyDirty()
            ->dontSubmitEmptyLogs();
    }

    public function tapActivity(Activity $activity, string $eventName): void
    {
        $props = $activity->properties ?? collect();
        if (! is_object($props) || ! method_exists($props, 'merge')) {
            $props = collect($props);
        }

        $activity->properties = $props->merge(array_merge(
            AuditContext::toArray(),
            ['retention_class' => $this->retentionClass($eventName)]
        ));
    }

    /**
     * Retention class for a given event. Override per model to return
     * 'critical' for deletes/approvals/etc.
     */
    public function retentionClass(string $eventName): string
    {
        return 'standard';
    }
}
```

namespace App\Services;

use App\Models\ActivityLog;
use App\Support\AuditContext;
use Illuminate\Database\Eloquent\Model;

class AuditService
{
    /**
     * @param  array<string, mixed>  $extra

    public function record(
        string $event,
        ?Model $subject = null,
        ?Model $causer = null,
        array $extra = [],
        string $retentionClass = 'standard'
    ): ActivityLog {
        return ActivityLog::create([

            'event' => $event,

            'causer_id' => $causer?->getKey(),
            'properties' => array_merge(
                AuditContext::toArray(),
                ['retention_class' => $retentionClass],
                $extra ? ['extra' => $extra] : []
            ),
        ]);
    }
}

class PruneAuditLogs extends Command

    protected $signature = 'audit:prune {--days=90}';

    protected $description = 'Delete standard-retention audit log rows older than the retention window.';

    public function handle(): int
    {
        $days = (int) $this->option('days');
        $cutoff = Carbon::now()->subDays($days);

        if (! config('database.connections.audit_pruner.username')) {
            $msg = 'AUDIT_PRUNER_DB_USERNAME not set — skipping prune.';
            $this->warn($msg);
            Log::warning($msg);

            return self::SUCCESS;
        }

        $deleted = DB::connection('audit_pruner')
            ->table('activity_log')
            ->where('created_at', '<', $cutoff)
            ->whereRaw("properties ->> 'retention_class' = 'standard'")
            ->delete();

        $this->info("Pruned {$deleted} standard audit rows older than {$days} days.");

        return self::SUCCESS;
    }
}
